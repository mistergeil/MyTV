# MyTV

Personal TV-style livestream page. Channels live in `channels.js`.

Keys: ↑/↓ channel, 0-9 number entry, L list, I info, F fullscreen, Backspace last channel.

## Repository layout

```
/                    the website (GitHub Pages): index.html, mediathek.html, channels.js, reminders.js
/data/               generated by GitHub Actions only: epg.json, highlights.json, youtube.json
/notebook/app/       switcher (mytv-vpn-agent.ps1), updater, installer, .bat files, VERSION + NOTES.txt
/notebook/remote/    iPhone/iPad pages served by the switcher: remote.html, watch.html
/notebook/tools/     one-off setup/diagnosis scripts (setup-webrtc.ps1, diag-cast-input.ps1)
/userscripts/        Tampermonkey sources: mytv-helper.user.js, mytv-vpn-bridge.user.js
/kiosk/              PUBLISHED (fixed URLs, don't edit by hand): setup page, MyTV-Windows.zip + version.json
                     (built by the Release workflow), userscript copies (python tools/sync_published.py)
/tools/              builders: build_epg.py, build_highlights.py, build_youtube.py, make_release.py
/tests/              ps.tests.ps1 (Windows PowerShell 5.1), web.test.js (Node) - run by CI on every push
```

**Release:** bump `notebook/app/VERSION`, write `notebook/app/NOTES.txt`, push. The *Release* workflow runs
the tests (incl. real Windows PowerShell 5.1) and only then builds `kiosk/MyTV-Windows.zip` + `kiosk/version.json`.
