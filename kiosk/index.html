MyTV on the TV notebook

One-time setup on Windows 11, about 10 minutes. Afterwards the notebook boots straight into MyTV and you zap through all channels with the arrow keys.

  1. Install Google Chrome

    If it's not already on the notebook.

    Get Chrome

  2. Download the MyTV scripts

    Unzip to a fixed place, e.g. C:\MyTV. Windows may warn about unknown .bat files: More info → Run anyway.

    Download MyTV-Windows.zip

  3. Run MyTV-Setup.bat

    Opens a separate “MyTV” Chrome profile with two tabs: Tampermonkey and this page.

    • In the Tampermonkey tab click Add to Chrome.
    • Open chrome://extensions → Tampermonkey → Details → turn on Allow User Scripts (on older Chrome: turn on Developer mode top right instead).

  4. Install the MyTV Helper script

    Still in that MyTV Chrome window, click the button — Tampermonkey opens, then click Install. Updates install themselves.

    Install MyTV Helper

  5. Close Chrome, then run MyTV-Kiosk.bat

    MyTV starts full screen with sound. Test a channel (e.g. 1 Das Erste): it should play on its own. Exit kiosk with Alt+F4.

  6. Log in to Joyn and RTL+ once

    With the VPN on Germany, run MyTV-Setup.bat, log in at joyn.de and plus.rtl.de (RTL+ Premium needed for live TV), accept the cookie notice, then close Chrome. The MyTV profile keeps you logged in.

  7. Optional: start automatically

    Run Autostart-Install.bat — MyTV starts after Windows login and the notebook won't sleep while plugged in. For a true TV box also turn on automatic sign-in for Windows. Undo with Autostart-Remove.bat.

Optional: automatic VPN (Proton Plus)

MyTV switches the VPN to Germany 🇩🇪, Switzerland 🇨🇭 or Austria 🇦🇹 by itself when you pick a channel that needs it (ZDF, SRF, ORF …). Uses WireGuard instead of the Proton app.

  1. Install WireGuard for Windows

    Get WireGuard

  2. Download two Proton WireGuard configs

    • Sign in at account.protonvpn.com/downloads → WireGuard configuration.
    • Platform Windows → pick a server in Germany → Create / download. Rename the file to DE.conf.
    • Same again for a server in Switzerland → rename to CH.conf, and in Austria → AT.conf.
    • Put the files into C:\MyTV\vpn\ (the folder from the zip).

  3. Run vpn\VPN-Install.bat

    Windows asks for admin rights — that's needed to switch the VPN. It installs a small switcher that starts with Windows (hidden) and only listens on the notebook itself. Remove it any time with VPN-Uninstall.bat.

  4. Install the MyTV VPN Bridge script

    In the MyTV Chrome profile (MyTV-Setup.bat) click the button, then Install in Tampermonkey. On first use Tampermonkey may ask to allow access to 127.0.0.1 → Always allow.

    Install MyTV VPN Bridge

  5. Quit the Proton VPN app

    Don't run the Proton app at the same time — two VPNs conflict. Start MyTV and pick ZDF (2): you'll see “VPN wird auf Deutschland umgestellt …”, then it plays.
